# contaHUB — Conciliação Contábil Inteligente

Plataforma profissional de conciliação contábil e bancária desenvolvida para o ecossistema contábil e fiscal brasileiro (Domínio Sistemas, Extratos Bancários OFX/XLSX/CSV, Boletos e Cooperativas).

## 🎨 Identidade Visual — Verde Petróleo Premium
- Tema **Verde Petróleo Escuro** com acentos em Ciano e Menta
- Visualização Bipartida em **Grafo Interativo** (`@xyflow/react`)
- **Tabela Didática** com busca em tempo real e vínculo manual com aprendizado De-Para
- Detecção inteligente de **Juros e Descontos em Boletos**

## 🚀 Como Executar

### Modo Web (Navegador)
```bash
npm install
npm run dev
```

### Modo Desktop Windows (Electron)
```bash
npm run electron:dev
```

### Gerar Executável (.exe) para Windows
```bash
npm run dist
```
